# Asanib setup — location, KYB and provider checkout

## Google Maps Platform

Enable the following APIs in the Google Cloud project used by Asanib:

- Places API (New)
- Geocoding API

Add the server-side Vercel environment variable:

- `GOOGLE_MAPS_API_KEY`

The key is used only by serverless API routes. Do not expose it through a `VITE_` variable.

Recommended Google Cloud restrictions:

- Restrict the key to the Places API (New) and Geocoding API.
- Use billing budgets and quota alerts.

## Firebase Storage for KYB

Enable Firebase Storage for the Asanib Firebase project and add these Vercel environment variables if they are not already present:

- `VITE_FIREBASE_STORAGE_BUCKET`
- `FIREBASE_STORAGE_BUCKET`

Deploy **Storage rules only** when ready:

```bash
firebase deploy --only storage
```

`storage.rules` limits provider KYB uploads to the provider's own `kyb/{uid}/` path and accepts PDF/image files below 10 MB. Admin document access is generated server-side with a short-lived signed URL.

## Firestore

This feature does not require new composite Firestore indexes. It also does not require a Firestore rules deployment: provider KYB/profile updates and admin review actions are handled by authenticated server routes using Firebase Admin.

## Asanib Checkout

External provider checkout links are implemented now. The separate embedded Ziina-powered **Asanib Checkout** path is feature-gated with:

- `VITE_ASANIB_CHECKOUT_ENABLED=false`

Leave this `false` until the Ziina Payment Intent/API flow and webhook verification are wired into Asanib.
