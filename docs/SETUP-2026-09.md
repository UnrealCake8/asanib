# JSV Market setup

## Location

Enable the Google Maps APIs used by the location autocomplete and details endpoints. Restrict browser and server keys to the required origins and APIs.

## Provider verification

Configure Firebase Authentication and Firestore, plus the private object-storage credentials used for KYB uploads. Verification files must never be public.

## Application URLs and gateway

Set `JSV_MARKET_APP_URL` to the approved deployment URL and configure `JSV_MARKET_WEBHOOK_SECRET` for gateway-authenticated endpoints.

## Checkout

Approved provider-hosted links can be reviewed and shown after booking. Keep `VITE_JSV_MARKET_CHECKOUT_ENABLED=false` and `PAYMENTS_ENABLED=false`.

Create a Network International service-account API key and note the outlet reference. Configure the webhook URL as `https://<market-host>/api/network-webhook`, add the custom header `X-JSV-Market-Webhook-Token`, and request webhook whitelisting in the N-Genius portal.

Validate the complete journey in sandbox before changing `NETWORK_INTERNATIONAL_ENVIRONMENT` to `live`. Live mode requires the approved live API key and outlet reference; secrets must remain server-only.
