# Asanib

Asanib is a mobile-first service marketplace: tell Asanib what you need, and find someone who can do it.

## V1 direction

- Customer natural-language service request
- Location, budget and urgency filters
- “Need it now” request mode
- Provider-facing portal
- Firebase Auth + Firestore backend
- Installable Progressive Web App
- Provider matching, quotes, bookings and ratings next

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

The app runs in prototype mode if Firebase environment variables are blank.

## Build

```bash
npm run build
```
